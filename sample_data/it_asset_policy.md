# Nexora Technologies — IT Asset & Equipment Policy

## 1. Standard Issue Equipment by Role

| Role Category | Laptop | Monitor | Accessories |
|---|---|---|---|
| Software Engineer | MacBook Pro 14" M3 / ThinkPad X1 Carbon | 1x 27" 4K | Keyboard, mouse, headset |
| Data/ML Engineer | MacBook Pro 16" M3 Pro (32GB) | 2x 27" 4K | Keyboard, mouse, headset, GPU cloud credits |
| Designer | MacBook Pro 16" M3 Pro | 1x 32" 4K color-calibrated | Wacom tablet, keyboard, mouse |
| Manager/Lead | MacBook Pro 14" M3 | 1x 27" 4K | Keyboard, mouse, headset |
| Intern | ThinkPad E-series or MacBook Air | 1x 24" FHD | Keyboard, mouse |

## 2. Refresh Cycle

- Laptops are refreshed every 3 years, or earlier if hardware fails diagnostic twice within 6 months.
- Monitors and peripherals are refreshed every 5 years or on failure.
- Employees may request an early upgrade with justification (e.g., ML workload, video editing); requires manager + IT Head approval.

## 3. Software & Licensing

- All engineers get a GitHub Copilot / Claude Code seat by default upon joining.
- JetBrains / IDE licenses issued on request via IT portal, approved automatically for engineering roles.
- SaaS tool requests (Figma, Notion, Datadog, etc.) over $50/month/seat require department head approval.
- Personal cloud API keys (OpenAI, Anthropic, etc.) are NOT reimbursed; use only company-provisioned/proxied API access for production or client work.

## 4. Remote Work Equipment

- Employees working hybrid/remote get a one-time $300 home office setup allowance (chair, desk, monitor arm) reimbursable within first 90 days.
- Company equipment taken home must be insured under the company's asset policy; loss/damage outside office requires an incident report within 48 hours.

## 5. Asset Return on Exit

- All hardware must be returned within 5 working days of last working day.
- Unreturned assets are deducted from final settlement at current depreciated value:
  - Year 1: 90% of original cost
  - Year 2: 60% of original cost
  - Year 3+: 30% of original cost (flat minimum)

## 6. Security Requirements

- Full disk encryption (BitLocker/FileVault) mandatory on all company devices, enforced via MDM.
- Company laptops must not be used for personal side-projects involving competing products.
- Lost/stolen device must be reported to IT Security within 1 hour; device is remote-wiped immediately.
- USB storage devices are disabled by default; exceptions require CISO approval.

## 7. FAQ

**Q: Can I use my personal laptop for work?**
No, BYOD is not permitted for engineering roles due to source code security requirements. Exceptions only for non-technical contractors with VDI access.

**Q: What if I need a second monitor at home?**
Covered under the $300 home office allowance if hybrid; fully remote employees get a dedicated home office budget of $500/year reviewed by IT.

**Q: Who approves GPU compute budget for ML experiments?**
Requests under $200/month are auto-approved via the internal cloud portal; above that requires ML Lead + Finance sign-off.
